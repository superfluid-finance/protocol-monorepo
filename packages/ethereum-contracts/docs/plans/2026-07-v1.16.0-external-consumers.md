# v1.16.0: external consumer migration

> **Planning doc** — 2026-07-02. Tracks required changes in repos **outside** protocol-monorepo for v1.16.0. Not maintained after downstream teams ship.

## Summary

v1.16.0 removes `build/truffle/` from the published `@superfluid-finance/ethereum-contracts` npm package and drops Truffle-based ops. Downstream repos must migrate artifact paths and ops workflows independently — **no cross-repo PRs from the protocol release**.

## `build/truffle/` removal

### Who is affected

| Consumer | Current usage | Required change |
|----------|---------------|-----------------|
| **scheduler-backend** | `require(".../build/truffle/<Contract>.json")` | Point at `build/hardhat/contracts/.../<Contract>.sol/<Contract>.json`, or use `build/bundled-abi.json` for ABI-only |
| **subgraph** (`scripts/getAbi.js`) | ~~Reads flat `build/truffle/*.json`~~ | **Fixed in monorepo** (v1.16.0): reads `build/hardhat/` artifacts |
| **clearmacro-provider** (`wagmi.config.ts`) | Imports truffle artifact paths | Update to hardhat nested paths or bundled ABI |

### Migration patterns

**ABI only (recommended when no bytecode/deployed address in artifact is needed):**

```javascript
const abis = require("@superfluid-finance/ethereum-contracts/build/bundled-abi.json");
const superfluidAbi = abis.Superfluid;
```

**Full artifact (bytecode + ABI):**

```diff
- require("@superfluid-finance/ethereum-contracts/build/truffle/Superfluid.json")
+ require("@superfluid-finance/ethereum-contracts/build/hardhat/contracts/superfluid/Superfluid.sol/Superfluid.json")
```

Path depth varies by contract; run `find node_modules/@superfluid-finance/ethereum-contracts/build/hardhat -name 'Superfluid.json'` after upgrading.

### Version pin

- Bump to `@superfluid-finance/ethereum-contracts@1.16.0` (or later `1.16.x` RC).
- Test compile/deploy in each consumer before production deploy.

## Ops / `truffle exec`

Repos or runbooks that invoked `npx truffle exec ops-scripts/...` against a linked `ethereum-contracts` checkout must switch to:

- `new-ops-scripts/` shell wrappers (see [ops-scripts-migration.md](../ops-scripts-migration.md))
- Foundry scripts under `foundry-scripts/` (e.g. `upgrade-framework.sh`)

Accepted gaps (no replacement yet): resolver list/unlist, `info-print-contract-addresses`, full testnet bootstrap — document internally until ported.

## js-sdk

`@superfluid-finance/js-sdk` is **deprecated** in v1.16.0. New app work should use **sdk-core** / **@sfpro/sdk**.

- ethereum-contracts tests no longer list js-sdk as a dependency (internal harness only).
- Apps still on js-sdk can keep the package until migrated; no new features planned.

## Yarn 4 (monorepo contributors only)

Contributors cloning protocol-monorepo need **Corepack** (`corepack enable`) and `yarn install --immutable`. This does not affect npm consumers of published packages.
